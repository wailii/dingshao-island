# 盯梢岛

防分心 App：开始专注后，你一打开会分心的 App，屏幕顶上的原子岛 / 灵动岛里就出现一双眼睛盯着你，待久了会催你回去。

## 下载

**[点这里下载 盯梢岛 v1.6（安卓，2.4 MB）](https://github.com/wailii/dingshao-island/releases/latest/download/dingshao-island-v1.6.apk)**

**怎么装**：用手机浏览器点上面的链接，下载完点开安装包。手机提示「未知来源」或「外部来源应用」时选允许（vivo 要先勾「已了解风险」再点继续安装）。

- 需要安卓 12 及以上。岛的效果要系统支持「实时活动」（安卓 16 的 Live Updates，vivo 原子岛、OPPO 流体云、小米超级岛这类）
- 第一次打开按提示开通知、无障碍和后台耗电，App 里每一步都有示意图
- 主要在 vivo（OriginOS）上测过，别的机型可以在 App 的「自检」页看哪一步没通

## 源码

- `dingshao/`：安卓工程（Kotlin），用 Android Studio 打开
- `island-probe/`：测试手机支不支持岛的小工程
- `真机截图/`、`效果图.png`：界面截图
